# 01. Manifiesto del Descubrimiento

En la mayoría de las blockchains, los tokens existen antes del valor. Se minan, se pre-venden, se especulan. El valor, si llega, llega después.

En Synexis Chain, invertimos esa lógica: **el valor existe antes del token**. El conocimiento se genera, se verifica, se certifica. Y solo entonces — cuando hay evidencia irrefutable de que la humanidad avanzó — se mintea el token que representa ese avance.

## El principio del vacío

En el bloque génesis de Synexis Chain, el supply de SYNA es exactamente **cero**.

- No hay tokens para founders.
- No hay tokens para inversores.
- No hay tokens para el equipo.
- No hay tokens para airdrops.
- No hay tokens para nadie.

El vacío es deliberado. Es la prueba de que nadie recibe nada sin haber generado conocimiento primero.

## El nacimiento de un token

Un token SYNA nace en un momento específico: cuando un Activo Inteligente dentro de Synexis Asset genera un descubrimiento que cumple con los criterios de verificación.

1. **Generación**: Un creador produce un avance verificable.
2. **Verificación**: Triple verificación — Oráculo + Nodos + Peer Review.
3. **Minteo**: El smart contract mintea SYNA proporcional al impacto del descubrimiento.

## El hard cap como horizonte

El hard cap de 1,000,000,000 SYNA no es una promesa de que existirán mil millones de tokens. Es un límite absoluto. Es posible que nunca se alcance. Si la humanidad no genera mil millones de descubrimientos verificables dignos de Synexis, no habrá mil millones de SYNA.

> "Cada SYNA es un certificado de contribución a la evolución del conocimiento humano."
