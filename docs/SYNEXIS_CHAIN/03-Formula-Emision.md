# 03. Fórmula de Emisión: Matemática del Conocimiento

> *Definida por CIDCITEI General Trading LLC — Mauro Manuel Herrera Mendoza*  
> *Modificaciones requieren autorización de CIDCITEI*

## Fórmula fundamental

```
SYNA_minteados = (II × FD × DR) / DF
```

| Variable | Significado | Rango |
|---|---|---|
| **II** | Índice de Impacto | 1 — 1000 |
| **FD** | Factor de Dominio | 0.5 — 3.0 |
| **DR** | Factor de Dificultad de Reproducción | 0.5 — 2.0 |
| **DF** | Deflator de Frecuencia | Variable |

## Rangos de emisión por descubrimiento

| Tipo | II | SYNA Minteados |
|---|---|---|
| Descubrimiento menor | 1-50 | 1,000 — 10,000 |
| Descubrimiento moderado | 51-200 | 10,000 — 100,000 |
| Descubrimiento mayor | 201-500 | 100,000 — 500,000 |
| Descubrimiento paradigmático | 501-1000 | 500,000 — 1,000,000 |

## Límite de emisión mensual

**Límite mensual = 10,000,000 SYNA** (1% del hard cap)

Si se supera, los descubrimientos excedentes se encolan para el mes siguiente.

## Burn como contrapeso deflacionario

- 30% de cada fee por servicio se quema permanentemente
- Servicios: certificación, simulación, análisis de IA, colaboración, licencias

> Si la red es muy utilizada (mucho burn) pero los descubrimientos son escasos (poca emisión), el supply circulante decrece.
